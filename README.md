  # 2D projectile motion
a website made to simulate the movement of an object with the given parameters on the x and y axis

  try it : https://halithsn2000-lab.github.io/physics-sim/2D.html

  ## How to use 
  - 1 put in the parameters on the right section
  - 2 press submit and watch the simulation
  - 3 press reset when you want to clear the canvas from past simmulations

  ##  Features
  - 1 fast simulations with accurate data
  - 2 access to details like : peak hieght , airtime , current X and Y possitions
  - 3 the ability to set parameters as high as wanted without limits unlike other simulators
  - 4 simple interface with no slop

  ## Why i built this project
  - 1 I wanted to code and do physics at the same time
  - 2 It can be scaled up to other projects like a 2d game
